JBAI — три варианта оформления

Одна и та же логика (поток ответа, история, стоп, очистка) и разные оболочки. Переключение: bash use_theme.sh business|hacker|jb — скрипт копирует выбранную тему в frontend/, после чего меняется только вид, код не трогается.

1. Деловая

Светлая, спокойная, «кабинетная»: сайдбар с разделами, синий акцент, аккуратные пузыри. Для бизнеса, клиентов и работы «в офисе».

открыть в полном размере →

2. Хакерская

Терминал: моно-шрифт, матричный фон, сканлайны, ASCII-логотип, приглашение root@jbai:~$. Для своих и для «техно»-подачи.

открыть в полном размере →

3. Фирменная JB

Фиолетово-циановая палитра проектов (#6a2bff · #9d00ff · #00e5ff), стекло, свечение, блок проектов JBVPN / JBAI / автоматизация.

открыть в полном размере →

Важно: это витрина внешнего вида. Чтобы чат реально отвечал, файлы должны отдаваться с того же домена, где живёт backend (nginx проксирует /api/ на backend). Если открыть файл напрямую с диска (file://), кнопка «Отправить» упрётся в отсутствие API — это нормально, вид от этого не меняется.
