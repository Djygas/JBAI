# Темы оформления JBAI

Три готовых оболочки для одного и того же чата. Логика везде одна и та же — во всех темах лежит **идентичный
`script.js`** (поток SSE, история диалога, кнопки «Стоп» и «Очистить»), различаются только `index.html` и `style.css`.

| Тема | Стиль | Для чего |
|---|---|---|
| `business` | светлая, сайдбар с разделами, синий акцент, мягкие тени | клиенты, бизнес-задачи, «офисная» подача |
| `hacker` | терминал: моно-шрифт, матричный фон, сканлайны, ASCII-логотип, приглашение `root@jbai:~$` | личное использование, техно-подача |
| `jb` | фирменная: `#6a2bff · #9d00ff · #00e5ff`, стекло, свечение, блок проектов | витрина проектов JBVPN / JBAI / автоматизация |

## Как посмотреть

- `preview.html` — все три темы рядом в уменьшенном виде, со ссылками на полный размер.
- `screenshots/` — десктоп (1440×900) и мобильный (390×844) вид каждой темы, снято в реальном браузере
  через полный стек nginx + backend с ответом-потоком.

## Как переключить

```bash
bash use_theme.sh business        # или: hacker | jb
docker compose up -d --build nginx
```

Скрипт копирует выбранную тему в `frontend/`, при первом запуске сохраняя прежнее оформление в `.frontend_backup/`.
Backend, ключи и `nginx/default.conf` не трогаются.

## Что важно в реализации

- **Никаких секретов во фронтенде.** Ключ модели живёт только в `backend/.env`; фронтенд ходит на свой `/api/chat`.
- **Доступ под паролем.** Basic Auth стоит в nginx на всех запросах, включая `/api/` — тема визуализирует
  состояние, но не является защитой.
- **Подписи статуса настраиваются.** Тема может задать свои слова, не меняя логику:

  ```html
  <script>
    window.JBAI_LABELS = { busy: "state: генерация…", ready: "state: готов", stopped: "state: прервано", error: "state: ошибка" };
  </script>
  <script src="script.js"></script>
  ```

  По умолчанию: `печатает… / готов / остановлено / ошибка`. В `jb` — «на связи», в `hacker` — «state: …».
- **Ответ остаётся потоковым.** Темы не трогают разбор SSE: текст появляется по мере генерации, с мигающим курсором.

## Как добавить свою тему

Скопируйте `frontend-themes/jb/` в `frontend-themes/<имя>/` и меняйте `style.css` (и разметку в `index.html`).
Обязательный контракт, который ждёт `script.js`:

| Что | Значение |
|---|---|
| id элементов | `chat`, `form`, `input`, `send`, `stop`, `clear`, `status` |
| прогресс потока | класс `.cursor` на элементе ответа (добавляется/снимается автоматически) |
| ошибки/опасное | цвет из CSS-переменной `--danger` |
| кнопки | `#stop` и `#clear` можно скрывать атрибутом `hidden` |
